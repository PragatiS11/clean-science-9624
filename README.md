
# 🛍️ Apna Shopping Center

### An Online E-Commerce Shopping Web Application

## 📌 About The Project

Apna Shopping Center is a user-friendly e-commerce web application developed to provide customers with a simple and convenient online shopping experience.

Users can create an account, log in, verify their identity through OTP verification, browse products, search and filter products, add items to their shopping cart, and place orders.

This project was developed individually using HTML, CSS, and JavaScript.

## ✨ Features

### User Authentication
- User signup and registration.
- Login functionality.
- OTP verification.

### Product Listing
- Display available products.
- Search products.
- Filter products by category.

### Shopping Cart
- Add products to cart.
- View selected products.
- Manage cart items.

### Order Placement
- Place orders for selected products.
- Navigate through the shopping process.

### Responsive Design
- User-friendly interface.
- Responsive layouts for different screen sizes.
